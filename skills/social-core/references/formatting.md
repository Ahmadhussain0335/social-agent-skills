# Formatting rules

General rules for all platforms. Platform skills add specifics.

- First line or first two seconds carry the hook; assume nothing after them is seen.
- Short paragraphs. A blank line between ideas.
- Links: put the most important link first. Use full URLs; do not use link shorteners
  that hide the destination.
- Lists: use plain hyphen bullets where the platform renders text only.
- Timestamps (YouTube descriptions): `00:00 Intro` format, first one at 00:00, at least
  three entries, each at least 10 seconds apart, so YouTube turns them into chapters.
- Mentions and tags: only accounts and topics that are relevant to the content.
- Language: match the audience language set by the user. Do not mix languages unless
  the voice file asks for it.
- Never include credentials, internal URLs, personal phone numbers or addresses unless
  the user explicitly asks for that exact detail to be published.
